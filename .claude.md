# Для Милы — романтический сайт

## Цель проекта
Романтическая интерактивная открытка-сюрприз: сайт на GitHub Pages, без Telegram-бота.

## Структура файлов
- index.html — разметка (конверт, неон, подсказка, кнопка звука), подключение three.js r128 с cdnjs
- style.css — стили и анимации: конверт, письмо, неон, 3D-холст
- script.js — 2D-звёзды, сердечки, three.js-сцена (туннель, галактика, 3D-солнце с шейдером, полёт), сценарий, музыка
- music.mp3 — фоновая мелодия, 16 с, сгенерирована ffmpeg (простой цикл из синусоид, без авторских прав)

## Сценарий
1. Тап 1: конверт открывается (клапан уходит назад), письмо выезжает вверх над конвертом. Включается музыка (громкость плавно до 0.3).
2. Тап 2: конверт и письмо улетают вверх. Начинается полёт сквозь звёздный туннель к галактике и 3D-солнцу (three.js, 7.5 с): скорость растёт, затем камера плавно останавливается перед солнцем. После полёта появляется огненная надпись. Через 2.9 с после полёта начинают падать сердечки.
3. Дальше тапы игнорируются.

## Музыка
music.mp3 лежит в корне и зациклен. Без файла звука нет, но кнопка 🔊/🔇 работает. Заменить можно любым mp3 с тем же именем.

## Технологии
HTML5, CSS3 (keyframes, transform, opacity, filter, mask, conic-gradient), Vanilla JavaScript, Canvas API, Google Fonts (Playfair Display, Comfortaa).
