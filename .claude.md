# Для Милы — Telegram Mini App

## Цель проекта
Романтическая интерактивная открытка-сюрприз в Telegram Mini App.

## Структура файлов
- index.html — разметка, подключение Telegram WebApp SDK
- style.css — стили, анимации (конверт, солнце, неон, кнопка звука)
- script.js — звёзды, сердечки, сценарий по тапам, музыка
- music.mp3 — фоновая мелодия, 16 с, сгенерирована ffmpeg (простой цикл из синусоид, без авторских прав)

## Сценарий
1. Тап 1: конверт открывается, выезжает письмо «Я люблю тебя, Мила.», включается музыка (громкость плавно до 0.3).
2. Тап 2: появляется солнце с вращающимися лучами и неоновый текст. Через 2.5 с начинают падать сердечки.
3. Дальше тапы игнорируются.

## Музыка
music.mp3 лежит в корне и зациклен. Если файл удалить, звук не играет, но кнопка 🔊/🔇 работает.
Чтобы заменить мелодию, положите другой mp3 с тем же именем.

## Технологии
HTML5, CSS3 (keyframes, transform, opacity, filter), Vanilla JavaScript, Canvas API, Telegram WebApp SDK, Google Fonts (Playfair Display, Comfortaa).

## Деплой
1. git init && git add . && git commit -m "init"
2. Создать репозиторий на GitHub, git remote add origin <url>, git push -u origin main
3. Settings → Pages → Branch: main, folder: / (root). Ссылка: https://<user>.github.io/<repo>/
4. @BotFather → /newapp → выбрать бота → название, описание, фото 640×360, ссылка на Pages
5. Проверка: открыть t.me/<bot>/<app> на телефоне
Альтернатива: Vercel или Netlify, перетащить папку проекта.
